BAGFOOT2: differential transcription factor footprinting from ATAC-seq

Leslie Cohen

BAGFOOT2 is a computational tool that predicts which transcription factors (TFs) change their activity between two experimental conditions using ATAC-seq data. It is an updated implementation of BaGFoot (Baek et al., Cell Reports, 2017), with motif clusters (archetypes) instead of individual motifs, robust statistics, and a one-line command-line interface. BAGFOOT2 is intended for biologists and bioinformaticians interested in chromatin accessibility and transcriptional regulation.

Code: https://github.com/goldsteinlab-tech/BAGFOOT2

Introduction

Input data

  • BAM files (aligned ATAC-seq reads), one merged BAM per condition
  • MACS2 peak files (narrowPeak or BED), one per condition
  • Optional (HOMER): one BAM per replicate

Core methodological components

BAGFOOT2 integrates footprinting, flanking accessibility, robust outlier statistics and (optionally) motif enrichment to infer TF activity changes between two conditions.

Footprinting and accessibility quantification. For every archetype motif, BAGFOOT2 computes the Tn5 sequence-bias-corrected footprint depth (FPD) and the flanking accessibility (FA) over all motif occurrences in peaks, in each condition, and their differences (ΔFPD, ΔFA).

Robust differential activity score. Each motif is a point in the (ΔFA, ΔFPD) plane. BAGFOOT2 measures how far each motif lies from the bulk of motifs with a robust Mahalanobis distance (D2), estimated with the Minimum Covariance Determinant (MCD, robustbase::covMcd()). Unlike the classical covariance, the MCD is not distorted by the TFs that truly change, so they are not masked. P-values are derived from a finite-sample F-distribution approximation of the robust distances (Hardin & Rocke 2005; Green & Martin 2017, via CerioliOutlierDetection) and adjusted for multiple testing (Benjamini–Hochberg FDR).

Motif enrichment (optional). BAGFOOT2 can identify differentially accessible peaks with HOMER (DESeq2) and run motif enrichment on them with the same archetype motifs. Enriched motifs are flagged in the results.

Visualization. BAGFOOT2 produces a bagplot of all motifs in the (ΔFA, ΔFPD) plane, and two ranked barplots of the significant motifs (by D2 and by −log10 FDR), split into TFs with increased and decreased activity in the treatment, with HOMER-enriched motifs labelled “ME”. All values are written to a CSV table.

Installation

BAGFOOT2 is distributed through conda:

conda create -n bagfoot2 -c goldsteinlab-tech -c conda-forge -c bioconda bagfoot2
conda activate bagfoot2

samtools must be available in the environment, as well as the BSgenome package of your genome (e.g. BSgenome.Mmusculus.UCSC.mm10, BSgenome.Hsapiens.UCSC.hg38). HOMER is optional (see below).

Project structure

1. Merged BAM directory (--bam_dir)

One merged, sorted and indexed BAM per condition, named <condition><bam_suffix> (default suffix _merged.bam), e.g. fed_merged.bam, fasted_merged.bam, each with its .bai index.

Chromosome names must be chr-prefixed (chr1, chr2, …).

2. Peak directory (--peak_dir)

One MACS2 peak file per condition, named <condition><peak_suffix> (default _peaks.narrowPeak), e.g. fed_peaks.narrowPeak.

3. Replicate BAMs (only if --homer TRUE)

In the same --bam_dir, one sorted and indexed BAM per replicate, named <condition>_<index>.bam:

fed_1.bam  fed_2.bam  fed_3.bam
fasted_1.bam  fasted_2.bam

Replicate numbers can differ between conditions (--reps_control 1,2,3 --reps_treatment 1,2).

4. Motif files (--mm_files_dir, optional)

Archetype motif occurrences (FIMO genome-wide scan) and motif lists. If --mm_files_dir is not given, the mm10 or hg38 files are downloaded automatically from Zenodo (https://zenodo.org/records/20782782; ~6.4 GB for mm10, ~7.1 GB for hg38) and cached. On a shared server, set the environment variable BAGFOOT2_MOTIF_DB_DIR to a folder that already contains the files to avoid downloading them again.

Expected content:

  • motiflist_<genome>_cluster.txt
  • <genome>_cluster_fimo/
  • all_cluster_motifs.motifs (for HOMER)

Quick start (command line)

bagfoot2 \
  --bam_dir    /path/project/bam_merged \
  --peak_dir   /path/project/macs2 \
  --output_dir /path/project/bagfoot2_fed_fasted \
  --control    fed \
  --treatment  fasted \
  --genome     mm10 \
  --cores      4

With HOMER (3 control vs 2 treatment replicates):

bagfoot2 \
  --bam_dir    /path/project/bam_merged \
  --peak_dir   /path/project/macs2 \
  --output_dir /path/project/bagfoot2_fed_fasted \
  --control fed --treatment fasted --genome mm10 --cores 4 \
  --homer TRUE \
  --homer_bin /path/homer/bin \
  --reps_control 1,2,3 \
  --reps_treatment 1,2

⚠️ The control is always given with --control and the treatment with --treatment. Positive ΔFA / ΔFPD means higher activity in the treatment.

Interrupted runs can simply be relaunched with the same command: the pre-processing files (BedGraph, hexamer tables) and the completed motif batches are detected and skipped.

How does BAGFOOT2 work?

Step 1 — Pre-processing (per condition)

ATAC-seq signal normalization

Observed vs. expected table. From each BAM, BAGFOOT2 counts the observed frequency of each 6-mer at Tn5 insertion sites and compares it to the expected genome-wide 6-mer frequency, giving an observed/expected (O/E) ratio per 6-mer.

Bias factor application. The O/E ratios are used as bias-correction factors to derive the expected count per position; observed counts are normalized by these expected counts before footprinting.

1. Nucleotide code files

For each chromosome, nuccode files (nuccode_<genome>_6mer_<chr>.dat) encode the 6-mer at each genomic position. They are generated automatically in the output directory during the first run, and reused if the run is relaunched.

2. BedGraph files

For each condition, a genome-wide cut-count BedGraph (<condition>_AC_cutcount.bgr.gz) is created. Reads are shifted to correct the Tn5 offset (+4 bp on the positive strand, −5 bp on the negative strand) and duplicates are removed.

3. Hexamer bias table

For each condition, BAGFOOT2 builds a hexamer table (Hexamer_<condition>_<genome>_withoutMap.txt). For every 6-mer, it:

  • counts its genomic occurrences (GenomicPositionCount),
  • sums the observed Tn5 cuts at these positions (ObCuts).

The ratio

      ObCutRatio = ObCuts / GenomicPositionCount

estimates the cleavage propensity of each 6-mer. The table also contains the genomic proportion of each 6-mer (GPRatio) and the derived correction factor used to remove Tn5 sequence bias.

4. Peak reformatting

MACS2 peaks are converted to a standardized table (<condition>_peaks.csv).

Step 2 — Merging the two conditions

Pre-processing outputs
Step Output (per condition) Output (control–treatment pair)
Nuccode files nuccode_6mer.dat (shared by both conditions)
BedGraph (Tn5 offset corrected) _AC_cutcount.bgr.gz
Hexamer table Hexamer___withoutMap.txt Hexamer___merged_withoutMap.csv
Peak reformatting _peaks.csv pooled___hotspot.csv (common peak universe)

Both conditions are therefore normalized with the same hexamer bias estimates and analysed on the same set of peaks.

Step 3 — HOMER: differential peaks and motif enrichment (optional)

HOMER must be installed following the official instructions (http://homer.ucsd.edu/homer/introduction/install.html), with the genome installed (perl configureHomer.pl -install mm10).

With --homer TRUE, BAGFOOT2:

  • creates a HOMER tag directory per replicate (TD_<condition>_<index>),
  • counts tags per pooled peak (annotatePeaks.pl),
  • runs the differential analysis with DESeq2 (getDiffExpression.pl),
  • keeps differential peaks (--peak_padj_cutoff, --peak_l2fc_cutoff),
  • runs motif enrichment on them (findMotifsGenome.pl) with the archetype motifs (all_cluster_motifs.motifs).

If no differential peak passes the thresholds, BAGFOOT2 prints a warning and continues without HOMER. If homer_motif_res/knownResults.txt already exists, HOMER is skipped.

Step 4 — Footprinting

For each condition, a CutCount object is created from the BedGraph. Footprinting is run with GFoot() on all archetype motif occurrences within the pooled peaks, using the merged hexamer table for bias correction (GFootOption()).

Motifs are processed in batches of 25 (output folders OUTPUT_<control>-<treatment>_<first motif>); finished batches are skipped when a run is relaunched.

For each motif, BAGFOOT2 quantifies:

  • footprint depth (FPD): depletion of Tn5 cuts over the motif core relative to its flanks (protection by the bound TF),
  • flanking accessibility (FA): Tn5 cuts in the regions surrounding the motif.

Step 5 — Statistics and visualization

All batch tables are merged into one table, with one row per motif, containing:

  • footprint depths in control and treatment (fdepth1, fdepth2),
  • mean cut counts (meancc1, meancc2),
  • log-ratio accessibility statistics (lrmotif, lrflanking, lrtotal),
  • the number of motif sites (numsite).

BAGFOOT2 then:

  1. computes ΔFA (lrtotal, treatment vs control) and ΔFPD for each motif,
  2. draws the bagplot: motifs are classified as bag, fence or outlier,
  3. estimates the robust centre and covariance of the motif cloud with MCD and computes the robust Mahalanobis distance D2 of each motif,
  4. derives p-values from the finite-sample F approximation and adjusts them (FDR),
  5. classifies outlier motifs by direction: increase (higher activity in the treatment), decrease (higher in the control) or discordant (ΔFA and ΔFPD of opposite signs),
  6. flags HOMER-enriched motifs (if HOMER was run),
  7. draws the D2 and FDR barplots of the significant (FDR < 0.05) increase and decrease motifs, and writes the result table.

Running BAGFOOT2 step by step in R

The command-line tool runs the code below. Running it in R is useful to inspect intermediate objects.

library(bagfoot2)

numcores <- 4

bg_dir   <- "/path/project/bagfoot2_fed_fasted/"   # output directory
bam_dir  <- "/path/project/bam_merged/"
peak_dir <- "/path/project/macs2/"
mm       <- "mm10"
assign("mm", mm, envir = .GlobalEnv)

mm_files_dir <- ensure_motif_db(mm)   # or the path to your motif files

set1 <- "fed"      # control
set2 <- "fasted"   # treatment

dir.create(bg_dir, showWarnings = FALSE, recursive = TRUE)
setwd(bg_dir)

# ---- Step 1: per condition ---------------------------------------------------
for (treat in c(set1, set2)) {
  bamfile <- file.path(bam_dir, paste0(treat, "_merged.bam"))

  countReadsBAM(bamfile, mm)
  makeCutCountBAMWithName(bamfile, name = treat, refgenome = mm)

  MakeBiasCorrectionTableBAM(
    bamfile   = bamfile,
    outfile   = paste0("Hexamer_", treat, "_", mm, "_withoutMap.txt"),
    refgenome = mm,
    np        = 6,
    atac      = TRUE,
    mapdir    = ""
  )

  macs <- read.table(file.path(peak_dir, paste0(treat, "_peaks.narrowPeak")),
                     sep = "\t", header = FALSE)
  nr <- nrow(macs)
  hotspot <- data.frame(ID = 1:nr, chrom. = macs$V1, start = macs$V2 + 1, end = macs$V3,
                        MaxD = 0, AveD = 0, Zscore = 0, pvalue = 0)
  write.table(hotspot, paste0(treat, "_peaks.csv"), sep = ",", row.names = FALSE)
}

# ---- Step 2: merge the pair --------------------------------------------------
combineTwoHotspots(paste0(set1, "_peaks.csv"), paste0(set2, "_peaks.csv"), set1, set2)

merge_two_frequency_tables(
  paste0("Hexamer_", set1, "_", mm, "_withoutMap.txt"),
  paste0("Hexamer_", set2, "_", mm, "_withoutMap.txt"),
  paste0("Hexamer_", set1, "_", set2, "_merged_withoutMap.csv")
)

# ---- Step 3 (optional): HOMER -------------------------------------------------
run_homer_step <- FALSE
homer_results_file <- NULL

if (run_homer_step) {
  homer_bin <- "/path/homer/bin"
  reps_ctrl  <- 1:3   # fed_1.bam, fed_2.bam, fed_3.bam
  reps_treat <- 1:2   # fasted_1.bam, fasted_2.bam

  peaks_homer <- paste0("pooled_", set1, "_", set2, "_hotspot_modify.txt")
  process_hotspot_file(paste0("pooled_", set1, "_", set2, "_hotspot.csv"), peaks_homer)

  # one HOMER tag directory per replicate
  td_dirs <- c()
  for (cond in c(set1, set2)) {
    reps <- if (cond == set1) reps_ctrl else reps_treat
    for (i in reps) {
      td <- file.path(bam_dir, paste0("TD_", cond, "_", i))
      if (!dir.exists(td)) {
        system(paste(file.path(homer_bin, "makeTagDirectory"), td,
                     file.path(bam_dir, paste0(cond, "_", i, ".bam")), "-format sam"))
      }
      td_dirs <- c(td_dirs, td)
    }
  }

  annot_out <- paste0(set1, "_", set2, "_annot.txt")
  diff_out  <- paste0(set1, "_", set2, "_output.txt")

  run_annotate_peak(homer_bin, bam_dir, peaks_homer, mm, td_dirs, annot_out)
  run_diff_expression(homer_bin, bam_dir, annot_out, diff_out,
                      rep(set1, length(reps_ctrl)), rep(set2, length(reps_treat)))

  create_diff_peak_files(input_path = bg_dir, input_filename = diff_out, sep = "\t",
                         chr = "Chr", start = "Start", end = "End",
                         padj_cutoff = 0.05, l2fc_cutoff = 0.5,
                         output_prefix = "my_peaks")

  run_homer(file.path(bg_dir, "my_peaks_simple.bed"),
            file.path(bg_dir, "homer_motif_res"), mm,
            file.path(homer_bin, "findMotifsGenome.pl"),
            paste("-mknown", file.path(mm_files_dir, "all_cluster_motifs.motifs"),
                  "-p", numcores))

  homer_results_file <- file.path(bg_dir, "homer_motif_res", "knownResults.txt")
}

# ---- Step 4: footprinting ----------------------------------------------------
assign(set1, CutCount(file = paste0(set1, "_AC_cutcount.bgr.gz"), count = 1, name = set1))
assign(set2, CutCount(file = paste0(set2, "_AC_cutcount.bgr.gz"), count = 1, name = set2))

motifdb <- MotifDB(
  motiflistfile = file.path(mm_files_dir, paste0("motiflist_", mm, "_cluster.txt")),
  directory     = file.path(mm_files_dir, paste0(mm, "_cluster_fimo"))
)

gfootoption <- GFootOption(
  biasfile        = file.path(bg_dir, paste0("Hexamer_", set1, "_", set2, "_merged_withoutMap.csv")),
  hexamer_pattern = paste0("nuccode_", mm, "_6mer_{chr}.dat")
)

couple   <- paste0(set1, "-", set2)
motif_no <- switch(mm, "mm10" = 577, "hg38" = 636)   # total number of motifs: do not change

for (r in seq(1, motif_no, by = 25)) {
  gf <- GFoot(
    control     = get(set1),
    treatment   = get(set2),
    sitefile    = file.path(bg_dir, paste0("pooled_", set1, "_", set2, "_hotspot.csv")),
    motifDB     = motifdb,
    gfootoption = gfootoption,
    outputdir   = paste0("OUTPUT_", couple, "_", r),
    cachedir    = paste0("CACHE_", couple, "_", r)
  )
  run(gf, graphout = TRUE, yrange = c(-2.2, 1.0), mc.cores = numcores,
      range = r:min(r + 24, motif_no), run_set = couple)
  gc()
}

# ---- Step 5: statistics and plots --------------------------------------------
merged_name <- paste0(set1, "_", set2, "_On_pooled_", set1, "_", set2,
                      "_hotspot_footprint_depth_table_merged.csv")
system(paste0("find . -type f -name '", set1, "_", set2, "_On_pooled_", set1, "_", set2,
              "_hotspot_footprint_depth_table.csv' -exec tail -n +2 -q {} ';' > ", merged_name))

dat <- data.table::fread(merged_name, header = FALSE, data.table = FALSE)
colnames(dat) <- c("num", "filename", "center", "logo", "motiflength", "motif",
                   "memeNo", "memeEntry", "lrmotif", "lrflanking", "lrtotal",
                   "fdepth1", "fdepth2", "meancc1", "meancc2", "numsite")

# Bagplot + D2 barplot + FDR barplot + CSV table with all values
# NOTE: dataname1 = treatment, dataname2 = control
gen_bagplot_bagfoot2(
  dat,
  dataname1             = set2,
  dataname2             = set1,
  include_homer_results = !is.null(homer_results_file),
  homer_results_file    = homer_results_file
)
